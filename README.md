Aesthetic Analog Clock 🕰️

A visually clean desktop clock application built entirely in Python using the Tkinter GUI framework. The project combines a traditional rotating analog face with a bold digital display. 

✨ Features

Real-Time Animation: Uses mathematical trigonometric coordinates (sin and cos) to update and rotate the clock hands dynamically every second. 

Dual Display: Shows both a classic minimalist dial and a large, high-contrast digital time readout with the day and date. 

Sleek Interface: Styled with a dark-mode theme to minimize desktop distraction. 

🛠️ Built With

Language: Python 3 

Libraries: tkinter (for GUI components and Canvas graphics), time / datetime (for fetching system time), and math (for hand coordinate calculations). 

🚀 How to Run

Make sure you have Python installed on your machine. 

Download or clone this repository. 

Open your terminal or command prompt in the project folder and run: 

bash

python clock.py 

Use code with caution.
